# Feishu Bitable Automation

飞书多维表格数据自动化工具，支持数据同步、清洗校验、统计分析和定时任务。

## 项目背景

在业务日常工作中，经常需要把不同来源的数据汇总到飞书多维表格里，再做清洗和校验。手动操作效率低且容易出错，这个工具把整个流程自动化了：自动拉取数据 → 清洗去重 → 异常检测 → 输出统计报告。

## 核心功能

1. **数据拉取**：从飞书多维表格读取指定表的全部记录
2. **数据清洗**：自动处理空值、格式不一致、重复数据
3. **统计分析**：自动计算数值列的均值、最大最小值，生成数据摘要
4. **定时任务**：支持定时自动执行同步流程
5. **执行日志**：记录每次执行的结果和统计信息

## 技术栈

- Python 3.10+
- 飞书开放平台 API（多维表格）
- Pandas（数据处理与统计）
- APScheduler（定时任务）

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 填入你的飞书应用凭证（APP_ID / APP_SECRET）

# 单次执行数据同步
python main.py sync

# 启动定时任务（每小时同步一次）
python main.py schedule --interval 3600
```

## 配置说明

需要在飞书开放平台创建一个自建应用，获取：
- APP_ID
- APP_SECRET
- 多维表格的 APP_TOKEN 和 TABLE_ID

并给应用开通多维表格的读写权限。
